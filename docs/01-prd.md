# Wio Memo 产品需求文档（PRD）

| 字段 | 内容 |
| --- | --- |
| 产品名称 | Wio Memo |
| 文档版本 | v0.4 Prototype |
| 目标硬件 | Seeed Studio Wio Terminal |
| 产品形态 | 桌面天气与提醒终端 + 局域网 Web 管理页 |
| 默认地区 | 深圳 |
| 核心原则 | Local-first、离线可用、无云账号 |

## 1. 产品定义

Wio Memo 是一台放在固定工位上的低干扰信息终端。它持续展示深圳天气和本地时间，在会议或待办到点时给出屏幕与蜂鸣提示，并允许用户通过同一局域网内的浏览器维护事项。网络断开后，设备仍保留本地 UI、RTC、已保存事项、提醒逻辑和小游戏。

它面向开源硬件、个人工作台和教学演示，不把当前原型包装成经过认证的消费电子产品。

## 2. 目标用户与场景

- 开发者、学生、设计师和固定工位办公人员。
- 希望减少手机通知干扰，但仍要看到时间、天气和下一事项的人。
- 学习 Wio Terminal、SAMD51、LVGL、局域网 WebServer 与嵌入式存储的创客。
- 需要在无云、内网或临时 AP 环境演示本地信息终端的团队。

典型流程：设备上电显示本地首页 → 后台连接已保存 Wi‑Fi → 成功后更新时间与深圳天气 → 用户在浏览器新增会议 → 设备保存并在到点时提示。

## 3. 产品目标

1. 上电后先显示本地 UI，联网过程不应造成白屏或按键长期失效。
2. STA 成功后清楚展示 SSID、设备 IP 和网页访问地址。
3. 无路由器时可开启 AP，并从 `192.168.5.1` 完成配置和事项管理。
4. 网络不可用时仍能浏览菜单、查看已保存事项、运行 RTC 和小游戏。
5. 提醒只触发一次，重启后不重复播放已经处理的旧事件。
6. 所有用户事项留在设备本地，不依赖账号和云数据库。

### P1：增强项

- 城市手动配置与可靠的 IP 定位。
- 稳定的 AQI 数据源与失败回退。
- Web 逐项编辑、搜索、重复任务和日历导入。
- 本地访问口令、恢复出厂设置和 OTA。
- 更完善的提醒确认、Snooze 操作与声音方案。
- 24 小时、7 天稳定性与故障恢复报告。

## 5. 明确不属于当前版本

- 公网远程访问、多账号协作和云端备份。
- GPS 定位、触摸屏、移动 App 或电池供电承诺。
- 企业微信、钉钉、飞书、Outlook、Google Calendar 直连。
- 生产认证、商业售后和量产硬件外壳。
- 完整 TLS 账号系统或把设备直接暴露在公网。

## 6. 数据模型

### 事项

| 字段 | 当前规则 |
| --- | --- |
| `id` | 设备内 `uint32` 标识 |
| `kind` | `todo` / `meeting` |
| `title` | UTF‑8，最多 48 字节 |
| `startAtUtc` | UTC Unix 秒 |
| `remindBeforeMinutes` | Web 提供 0/5/10/30 分钟 |
| `status` | pending/completed/cancelled |
| `alertFlags` | 提前、开始等事件触发标记 |
| `updatedAtUtc` | 最近更新时间 |

设备最多保存 12 条事项。当前 Web API 采用整表替换，不提供多客户端冲突合并。

## 7. 交互规则

- 首页优先展示天气、时间和网络状态，下一事项作为辅助信息。
- 五向摇杆负责二维菜单导航；确认动作必须立即显示视觉反馈。
- 网络切换前显示确认提示，切换过程保留本地 UI。
- AP 页显示热点名称、访问地址和当前模式；STA 页显示 SSID 与设备 IP。
- 网络或天气失败时保留离线界面，不把加载状态无限覆盖在主内容上。
- 静音只关闭声音，不删除提醒状态。

## 8. 非功能指标

| 类别 | 原型目标 |
| --- | --- |
| 本地启动 | 5 秒内出现可操作界面 |
| 按键反馈 | 正常页面下 100 ms 内可见 |
| 网络超时 | 连接与请求均有有限超时，失败后回到可操作状态 |
| RAM | 峰值控制在 75% 以下 |
| 主程序 Flash | 当前已约 90%，必须先优化再扩展 |
| 存储 | 避免无变化周期写入；读取时校验 CRC |
| 安全 | 默认仅可信局域网；不宣传公网可用 |
| 稳定性 | 先完成 24 小时观察，再进行 7 天验收 |

## 9. 成功标准

- 20 次事项新增/完成/删除后，Web 与设备数据一致。
- 提前提醒和准时提醒各触发一次，重启不重放旧提醒。
- STA、AP、离线三种模式均能回到可操作界面。
- 外网不可用时，本地菜单、RTC、事项和游戏继续工作。
- 5 名试用者中至少 4 名可根据屏幕信息找到局域网页面并完成一次配网。
