# Wio Memo 设备与 Web UI 规范

## 1. 视觉方向

Wio Memo 使用暖白、浅米色、青绿和珊瑚橙，目标是安静、清楚、有桌面产品感，而不是高密度工程调试界面。

- 背景：暖白或浅米色，避免大面积纯白刺眼。
- 主色：青绿用于网络、同步和次级强调。
- 强调色：橙色用于天气、焦点、提醒和关键数值。
- 文字：深灰主信息、灰蓝辅助信息，保证实际 LCD 对比度。
- 卡片：圆角、轻边框、有限阴影；320×240 屏幕不使用复杂透明层。
- 动画：150–200 ms 的轻位移、翻页或呼吸，不阻塞按键与提醒。

## 2. 页面结构

### 2.1 启动与待机

启动页展示 Wio Memo 小助手和一句简短提示。启动完成后进入天气首页。待机状态保留小助手与时间，任意按键可以唤醒；它是产品识别元素，不应遮挡天气主图标。

### 2.2 深圳天气首页

顶部必须使用两级城市信息：

```text
Shenzhen                 10:30
深圳市                 2026/08/04 Tue
```

主体采用一张当前天气主卡、两张指标卡和三张预报卡：

```text
┌──────────────────────────────────────┐
│ Shenzhen                    10:30    │
│ 深圳市                 2026/08/04 Tue│
├───────────────────────┬──────────────┤
│ 天气图形  晴间多云     │ 湿度  65%    │
│           28°C         ├──────────────┤
│           实时天气     │ AQI  --      │
├───────────┬───────────┬──────────────┤
│ 明天      │ 后天      │ 大后天       │
│ 24° / 30° │ 25° / 31° │ 24° / 29°    │
└───────────┴───────────┴──────────────┘
```

AQI 没有实时数据时显示 `--`，不得展示伪造数值。联网成功后“离线预览”改为“实时天气”；请求失败时保留最后有效数据或深圳预览。

### 2.3 时钟页

- 与首页保持同一暖白卡片体系。
- 顶部显示 `Shenzhen` 和 `深圳市 · 本地时间`。
- 中央为六位数码段 `HH:MM:SS`；时、分用橙色，秒用青绿色。
- 冒号以 500 ms 节奏轻闪，数字变化做短距离翻页位移动画。
- 日期位于右上角，未校时时明确显示“等待对时”。

### 2.4 主菜单

使用 3×2 卡片网格：时钟、待办、网络、游戏、设置、首页。摇杆上下左右移动焦点，按下进入；焦点使用边框、底色和轻微缩放共同表达，不只依赖颜色。

### 2.5 网络页

| 当前模式 | 必须展示 |
| --- | --- |
| STA | “局域网”、当前 SSID、设备 IP、`http://设备IP/` |
| AP | “设备热点”、热点名称、访问地址 `http://192.168.5.1/`；密码只在确有必要时展示 |
| 连接中 | 目标 SSID、有限等待提示、可返回 UI |
| 离线 | 本地功能仍可用的说明 |

“连接已保存 Wi‑Fi”“开启设备热点”“离线”均需要确认提示。切换网络不能让页面永久停在加载状态。

### 2.6 任务与提醒

任务页显示排序后的未完成事项，提供完成动作。提醒到点时应覆盖普通内容，展示类型、标题、时间与清晰动作；声音和 UI 状态分离，静音不等于忽略提醒。

### 2.7 游戏

游戏选择页包含点灯、记忆翻牌、打砖块和俄罗斯方块。游戏均离线运行，离开游戏后必须释放/重置页面对象，提醒检查仍在主循环中执行。

## 3. 物理按键原则

- 五向摇杆：上下左右导航，按下确认。
- 顶部快捷键：菜单、返回/主页、静音等动作以当前固件映射为准。
- 屏幕底部只显示自然语言小贴士，不显示与实际按键不一致的 `A/B/C` 硬编码提示。
- 缺少字形时改用已有字词表达；不可直接把方框或乱码留给用户。

## 4. Web 页面

### 当前能力

- 设备状态、网络模式、IP 和时间。
- Wi‑Fi 扫描、STA/AP 配置和模式切换。
- 待办/会议新增、完成、删除和整表保存。
- 桌面与手机窄屏布局。

### 交互要求

- 提交网络配置前说明设备可能暂时断开，保存后提示去哪里重新访问。
- 密码输入默认遮挡。当前状态 API 会返回 AP 密码以便在网络页展示热点凭据，但不返回 STA 密码；因此页面只能用于可信局域网。
- 保存事项失败时保留本地表单，不静默丢失输入。
- 不显示“云同步”“账号登录”等当前不存在的能力。
- AP 与 STA 页面使用同一套 HTML，依靠状态接口更新实际地址。

## 5. 字体与渲染

- 中文使用 QSPI 中的 12/16/20 px WMF1 字库；ASCII 使用 LVGL 内置字体回退。
- 字库包包含 7,445 个 GB2312 字符，总大小约 934 KiB。
- 使用 LVGL 局部缓冲和脏矩形刷新，不在普通循环中调用整屏 `fillScreen()`。
- 常规界面目标为稳定响应而不是高帧率；任何动画都必须允许按键和提醒继续处理。
