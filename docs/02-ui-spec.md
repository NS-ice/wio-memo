# Wio Memo UI 方案

## 1. 设计原则

- 桌面设备只承担“看见、提醒、快速处理”，复杂编辑放到 Web。
- 一屏只强调一个主信息：普通状态强调下一项，提醒状态强调当前事件。
- 使用类型文字和图形共同区分待办/会议，不仅依赖颜色。
- 关键动作始终与物理键位置对应，减少记忆成本。

### 2.3 状态页

显示设备名、IP、Wi-Fi 信号、最近校时时间、固件版本和配网二维码/地址。长按 B 进入，五向左返回。

## 3. Web 端信息架构

### 3.1 今日页

- 顶部：设备名、在线状态、设备当前时间、设置入口。
- 主区：快速新增表单；今天/已过期/已完成分组列表。
- 单条事项：完成框、类型、标题、时间、提醒策略、编辑和删除。
- 手机窄屏下改为单列，不保留横向表格。

### 3.2 添加/编辑事项

- 标题为唯一首屏必填字段。
- 类型使用“待办/会议”分段选择。
- 日期时间默认下一整 5 分钟。
- 高级选项折叠：结束时间、提醒提前量、重复规则（P1）。

### 3.3 设备设置

- 网络：SSID、连接状态、重新配网。
- 时间：时区、NTP 状态、立即同步。
- 提醒：音量、默认提前量、试听。
- 设备：亮度、名称、版本、重启、恢复出厂设置。

## 4. 状态与反馈

| 状态 | 设备端 | Web 端 |
|---|---|---|
| 正常在线 | Wi-Fi 实心图标 | 绿色点 + “刚刚同步” |
| 断网 | 顶栏断网图标，不遮挡列表 | 顶部警告，可继续编辑并等待重连 |
| 时间未同步 | 时间旁显示 `!` | 禁止创建早于当前浏览器时间的提醒并解释原因 |
| 保存中 | 不阻塞按键 | 行内进度状态 |
| 保存失败 | 保留旧列表并显示短错误 | 不清空表单，提供重试 |
| 已逾期 | 时间前显示 `!` | 进入“已过期”分组 |
| 静音 | 顶栏持续显示 | 设置页与首页同步显示 |

## 5. 字体方案

正式 MVP 必须解决中文。已确定将开源中文字体转换为 WMF1 单色点阵字库并存放在板载 4 MB QSPI Flash，以 UTF-8 按需查字并设置缺字占位符，不要求安装 microSD。设备标题允许两行，每行约 12–16 个中文字符，超出使用省略号；Web 仍限制 UTF-8 字节长度以匹配设备存储。
