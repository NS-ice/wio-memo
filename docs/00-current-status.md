# Wio Memo 当前状态清单

> 状态日期：2026-08-01
> 当前代码定位：正式架构 Milestone 1。核心已从技术原型中拆出，但尚未经过 Wio Terminal 实机验收。

## 已完成并通过编译的功能

| 模块 | 已有功能 | 当前状态 |
|---|---|---|
| Wi-Fi | STA 模式连接指定 Wi-Fi；失败后进入 AP 模式 | 已编码、已编译，待实机联网测试 |
| Web 管理 | 设备提供局域网网页；读取、添加、删除、完成事项 | 已编码、网页脚本语法检查通过，待真机浏览器测试 |
| 事项模型 | 待办/会议、标题、开始时间、提前提醒、完成状态 | 已编码 |
| 本地存储 | 最多 12 条；schema v2、sequence、CRC32 和逻辑 A/B 双槽 | 已编码、已编译，待断电恢复测试 |
| 时间 | NTP 获取 UTC，写入板载 RTC，默认 UTC+8 显示 | 已编码、已编译，待网络与时钟漂移测试 |
| 设备显示 | 320×240 屏幕显示时间、网络状态和按时间排序的事项 | 已编码、已编译，待实机视觉检查 |
| 本地交互 | 五向键上下选择/按下完成；C 静音；B 手动校时 | 已编码、已编译，待按键测试 |
| 声音提醒 | 提前/开始/稍后提醒事件；非阻塞两段蜂鸣 | 已编码、已编译，待确认音量和节奏 |
| 中文字库 | WMF1 格式、UTF-8 解码、QSPI 二分查字、点阵渲染 | 已编码；7,445 字 16×16 字库约 298 KB，待实机烧录与显示验收 |
| 字库安装 | 独立安装固件、串口 512 B 分块、读回 CRC32 验证 | 已编码、两个工具均已验证构建 |
| 核心测试 | CRC、排序、状态保留、提醒去重、旧提醒、Snooze、时区与 `millis()` 回绕 | native 测试 7/7 通过 |
| 容量 | 正式固件 148,104 B Flash、60,484 B RAM | 已验证（Flash 约 29.2%，RAM 约 30.8%） |

## 还没有完成的产品能力

- 首次使用的网页配网流程；当前正式联网仍需写 `secrets.h` 后重新烧录。
- 开源中文字体资产的许可归档、真机字形效果和自动换行。
- 事项编辑、批量操作、重复任务、全天事项、会议结束时间。
- 提醒确认、稍后提醒（Snooze）、过期提醒策略。
- 多设备同步、账号、云端备份、手机跨网络访问。
- Web 鉴权、TLS、配网凭据安全存储。
- OTA 固件升级、日志导出、恢复出厂设置。
- 断网重连、NTP 失败、Flash 损坏等完整异常状态 UI。
- Web 接口测试、长时间稳定性测试和真机验收。

## 结论

Milestone 1 已完成领域/应用核心、版本化存储、非阻塞蜂鸣器和板载 QSPI 字库链路。下一阶段应完成首次配网、非阻塞网络状态机、正式 Web API 和设备提醒交互，再进入真机验收。
