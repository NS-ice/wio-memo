# Wio Memo 离线优先与 LVGL 实现说明

## 产品原则

Wio Memo 是能够独立工作的桌面设备，不是必须连接电脑的网页外设。

- 无互联网：保留 RTC、菜单、已保存事项、提醒逻辑和小游戏。
- 无路由器：可开启 AP，手机或电脑直连本地网页。
- 有局域网：设备作为 STA，浏览器通过设备 IP 管理网络和事项。
- 有互联网：在局域网能力之外更新深圳天气与时间。

## 当前网络模式

| 模式 | 行为 |
| --- | --- |
| 自动启动 | 优先连接已保存 Wi‑Fi；无配置时进入 AP |
| 局域网 STA | 连接路由器，显示 SSID、设备 IP 和访问地址 |
| 设备热点 AP | 开启设备热点，访问 `192.168.5.1` |
| 离线 | 关闭无线，本地 UI 保持运行 |

网络页允许在 STA、AP 和离线之间切换。模式切换被拆成停止、等待和启动三个阶段，避免无线协处理器切换时长时间占用界面循环。

## 页面树

```text
启动小助手
└─ 深圳天气首页
   ├─ 时钟（HH:MM:SS）
   ├─ 待办与会议
   ├─ 网络模式
   ├─ 益智小游戏
   │  ├─ 点灯谜题
   │  ├─ 记忆翻牌
   │  ├─ 打砖块
   │  └─ 俄罗斯方块
   ├─ 设备设置
   └─ 待机小助手
```

摇杆上下左右移动焦点，按下确认。顶部快捷键负责菜单、返回/主页和静音等动作。具体映射以当前固件页面提示为准，文档不再使用可能过期的 A/B/C 固定位置描述。

## LVGL 渲染策略

- LVGL 8.3.11 + TFT_eSPI。
- 屏幕逻辑分辨率 320×240，旋转由显示初始化统一设置。
- 使用局部 RGB565 缓冲与 LVGL 脏矩形刷新，不分配完整帧缓冲。
- 页面切换重新创建页面对象；持续动画仅作用于天气图形、宠物、数字或焦点等小区域。
- 常规循环持续处理按键、提醒和蜂鸣器，动画不使用长 `delay()`。
- 中文字形从 QSPI 按需读取，ASCII 使用内置字体回退。

## 调度策略

默认固件当前采用协作式 `loop()`，而不是启用 FreeRTOS 双任务。每轮先保证 UI/提醒，再推进网络、Web 和天气阶段。FreeRTOS 相关依赖与代码仍在仓库中，用于后续实验，但不属于当前稳定运行路径。

## 离线行为

- 天气：显示深圳预览或保留当前页面；不会因为请求失败进入空白屏。
- 时间：RTC 有效时继续走时；未校时时显示明确占位。
- 事项：从 Flash 恢复，可查看和完成；Web 在完全离线模式下不可用。
- 提醒：根据 RTC 与持久化标记判定；静音只影响声音。
- 游戏：四款游戏不依赖网络。
- 字体：来自板载 QSPI，与 SD 卡和互联网无关。

## 验收清单

1. 断开路由器并重启，5 秒内出现可操作首页。
2. Wi‑Fi 关闭时，菜单、时钟、任务和四款游戏可以进入和返回。
3. AP 模式下，无互联网手机能够打开 `192.168.5.1`。
4. RTC 有效时，断网后提醒继续判定且旧事件不重复播放。
5. 网络连接、天气失败和模式切换均不会造成永久卡死。
6. 普通静态页面没有肉眼可见的周期性全屏闪烁。
7. 最新实机照片与渲染海报分开归档，宣传图不作为验收证据。
