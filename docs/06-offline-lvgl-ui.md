# Wio Memo 离线优先与 LVGL UI 设计

## 产品原则

Wio Memo 是一台可以独立工作的桌面设备，不是必须依赖电脑或互联网的“网页外设”。

- 无互联网：本地时间、待办查看与完成、会议提醒、菜单、设置和小游戏可用。
- 无路由器：设备可开启 AP，手机或电脑直连后访问本地网页。
- 有局域网：设备可加入现有 Wi-Fi，局域网内浏览器管理事项。
- 有互联网：在局域网能力之外增加 NTP 校时；互联网不是核心功能前提。

## 网络模式

设备设置菜单提供四种模式，并保存用户选择：

| 模式 | 行为 |
|---|---|
| 自动 | 优先连接已保存 Wi-Fi；超时后进入 AP，但 UI 始终可用 |
| 局域网 | 作为 STA 连接路由器，浏览器通过设备局域网 IP 访问 |
| 设备热点 | 开启 `WioMemo-xxxx` AP，浏览器访问 `192.168.4.1` |
| 离线 | 关闭 Wi-Fi，降低功耗；设备本地功能完整可用 |

网络连接、重连和 NTP 全部采用非阻塞状态机。开机先显示本地首页，再在后台处理网络。

AP 页面不仅用于首次配网，也能直接管理任务、会议、时间和设备设置。没有互联网时可以通过浏览器或设备菜单手动设置 RTC。

## 页面结构

```text
首页
├─ 下一事项卡片
├─ 今日待办摘要
├─ 卡通助手与状态提示
└─ 状态栏：时间 / Wi-Fi 模式 / 静音

主菜单
├─ 待办与会议
├─ 网络
├─ 时钟与提醒
├─ 小游戏
│  ├─ 2048
│  └─ 点灯谜题
└─ 设备设置
```

五向键用于移动焦点和确认，顶部 A 键返回首页、B 键打开菜单、C 键作为返回/静音快捷键。提醒弹窗优先级最高，但允许完成、确认和稍后提醒。

## LVGL 渲染策略

- 使用 LVGL 8 与 TFT_eSPI 显示驱动，不申请 320×240 完整 RGB565 帧缓冲。
- 使用两个 320×12 RGB565 局部缓冲区，约占 15 KB RAM。
- 由 LVGL 脏矩形机制只刷新变化区域，禁止周期性 `fillScreen()`。
- 常规界面目标 20–30 FPS；按键反馈在 100 ms 内出现。
- 页面切换动画控制在 150–200 ms，提醒与任务调度不被动画阻塞。
- 中文字形继续从板载 QSPI 按需读取；ASCII 使用 LVGL 内置字体。

## 视觉方向

- 风格：奶油白、薄荷蓝、珊瑚橙，圆角卡片和低对比背景。
- 卡通助手只使用小型离线精灵图，不从网络加载。
- 卡通素材缩小到约 64–80 px，并转换为设备可直接读取的格式。
- 动画以眨眼、轻微呼吸和提示气泡为主，避免大面积连续动画。

## 离线验收条件

1. 断开路由器并重启，1 秒内出现本地首页，不显示空白屏或持续等待网络。
2. Wi-Fi 完全关闭时，可以浏览菜单、完成任务、静音和运行小游戏。
3. 设备 AP 模式下，无互联网的手机仍可打开管理网页并修改任务。
4. RTC 有效时，断网后会议和待办提醒继续按时触发。
5. 网络重连、网页访问和 NTP 不造成屏幕卡顿或错过按键。
6. 静态页面没有肉眼可见全屏闪烁。

## 实施顺序

1. LVGL 显示、输入和 QSPI 中文字体适配。
2. 离线首页、任务页、主菜单和提醒弹窗。
3. AP/STA/离线非阻塞网络状态机与设置页。
4. 2048、点灯谜题及卡通助手轻动画。
5. 实机帧率、RAM 峰值和长时间运行测试。
