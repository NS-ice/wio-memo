# Wio Memo 分阶段交付计划

## 阶段 0：产品确认

- 评审 PRD 中 5 个待确认问题。
- 冻结 MVP P0 范围、设备交互和中文方案。
- 输出：PRD v1.0、UI v1.0、架构决策记录。

## 阶段 1：工程重构与可测试内核

- 将当前单文件 Prototype 拆成 domain/application/infrastructure/presentation。
- 建立 native 单元测试和版本化数据模型。
- 验收：排序、提醒去重、稍后提醒、时间跳变和存储 CRC 测试通过。

## 阶段 2：设备基础能力

- 完成非阻塞网络状态机、NTP/RTC、双槽 Flash、看门狗。
- 完成配网页和网络自动恢复。
- 验收：断网/错误密码/断电不阻塞本地 UI，数据不丢失。

## 阶段 3：UI 与核心业务

- 实现正式设备列表页、提醒页、状态页和中文字体。
- 实现 Web CRUD、编辑、错误状态和响应式布局。
- 验收：Web 保存 2 秒内刷新设备；所有 P0 UI 状态可复现。

## 阶段 4：硬件验收

- 校准蜂鸣器音量和两类声音节奏。
- 测试按键消抖、屏幕刷新、RTC 漂移和连续运行。
- 进行 PRD P0 全量验收并输出问题清单。

## 阶段 5：发布

- 固定依赖版本、生成 BIN/UF2、烧录说明和恢复流程。
- 标记 v1.0.0，保留 Prototype 与正式实现的迁移说明。
