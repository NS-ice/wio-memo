## 发布候选条件

- 最新界面、网络和提醒均有对应实机证据。
- STA/AP 重复切换至少 20 次无冻结。
- native 7/7 与嵌入网页检查通过。
- 构建输出、字体包、烧录顺序和恢复步骤可由另一台电脑复现。
- README 中所有“已实现”陈述都能映射到代码或验收记录。
