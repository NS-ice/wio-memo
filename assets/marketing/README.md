# Wio Memo 宣传素材

## 多页产品画册

`carousel/` 是 README 当前使用的四页竖版产品宣传图：

| 页码 | 文件 | 内容 |
| --- | --- | --- |
| 01 | `01-cover-real-device.png` | 品牌封面、真实 Wio Terminal 产品结构与总体功能 |
| 02 | `02-weather-clock.png` | 深圳天气、三日预报、RTC 与秒钟时钟 |
| 03 | `03-local-web-reminders.png` | STA/AP、局域网页面、待办与会议 |
| 04 | `04-offline-games.png` | 小助手、离线提醒与四款小游戏 |

四页沿用早期纵向海报的暖色、留白、木质桌面和产品目录风格。实机照片只用于确认硬件结构和已经出现过的界面；每一页均重新生成产品角度、灯光、背景和屏幕排版，没有直接裁切或拼贴实拍。

真实设备约束包括：

- Wio Terminal 紧凑白色机身与厚黑色屏幕边框。
- 320×240 横向 LCD 比例。
- 右侧蓝色圆形五向摇杆。
- 机身侧键、接口和通风开孔。
- 不增加虚构的前面板按键、橙色滑块、触摸屏或大型定制外壳。

注意：宣传图不是实机验收截图；时间、天气数值、任务标题与游戏分数用于视觉演示。真实功能状态以代码、自动测试和 `docs/00-current-status.md` 为准。

## 生成方式

四页均使用内置图像生成模式制作：第一页属于基于原海报的 `precise-object-edit`，重点替换真实设备；后三页属于 `ads-marketing`，分别展开天气时钟、局域网与离线能力。第四页另外进行一次局部修正，将错误的重复打砖块画面替换为 3×3 点灯谜题。
