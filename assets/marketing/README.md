# Wio Memo 宣传素材

## `wio-memo-poster-wide.png`

横向项目主海报，用于 GitHub README、项目介绍和展示屏。它由图像生成工具依据五张 Wio Terminal 实机照片重新渲染：参考内容仅包括真实硬件比例、黑色屏幕边框、白色机身、蓝色摇杆，以及已经在实机中出现过的小助手、天气、菜单和打砖块界面。

原始实拍没有被裁切、拼贴或直接放入海报。海报重新建立了桌面背景、产品角度、灯光、界面排版和功能分区。

注意：

- 海报是宣传渲染图，不是量产产品照片或实机验收截图。
- 海报中的天气数值、时间与分数用于版式展示，不代表实时数据。
- 海报没有宣称 GPS、触摸屏、电池、云同步、移动 App 或生产认证。
- README 的功能状态以代码、自动测试和 `docs/00-current-status.md` 为准。

## `wio-memo-poster.png`

早期纵向宣传图，保留用于版本对比。项目首页优先使用新的横向海报。

## 生成说明

横向海报使用内置图像生成模式制作，任务类型为 `ads-marketing`。核心提示要求是：16:9 横向商业产品构图、重新渲染真实 Wio Terminal 外形、左侧深圳天气主设备、右侧小助手/菜单/打砖块分区、暖白与青绿/橙色配色，并严格避免直接使用原照片和宣传不存在的能力。
